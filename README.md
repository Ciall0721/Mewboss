# Mewboss

把 **Mewgenics** 的 BOSS 移植进《以撒的结合：忏悔+》的粉丝 MOD。
目前只做了三个，会努力不定期更新的。

- 当前版本：**1.0.0**
- 适用游戏：**The Binding of Isaac: Repentance+ v1.9.7.17.J460**
- 可选依赖：[StageAPI](https://steamcommunity.com/sharedfiles/filedetails/?id=1348031964)（创意工坊 id `1348031964`）

---

## BOSS 一览

| 实体 | ID | 出现楼层 | 机制概要 |
|---|---|---|---|
| Zodiac | 501 | 地下室 / 地窖 / 燃烧地下室 I–II | 蓄力狙击：同轴无遮挡时锁定玩家，蓄力 1~2 秒后攻击 |
| Man in the Moon | 502 | Mines / Ashpit I–II（2.5 章） | 静止的减伤光环 BOSS，带两个可推挤的 Moon Hand |
| Moon Hand | 503 | 由 Moon 召唤 | 怪物 / 石头双形态随从 |
| Gambit | 506 | 地下室 / 地窖 / 燃烧地下室 I–II | 六面骰驱动六种攻击形态 |
| Gambit Die | 507 | 由 Gambit 投出 | 可被推动、碰撞重投的六面骰 |

## 安装

### 创意工坊

1. 订阅本 MOD。
2. 推荐同时订阅 **StageAPI**。
3. 在游戏的「模组」菜单中启用，重启游戏。

### 手动安装

1. 解压 `mewboss_v1.0.0.zip`。
2. 把其中的 `mewboss/` 文件夹放进：

   ```
   The Binding of Isaac Rebirth/mods/
   ```

3. 在「模组」菜单里启用 `Mewboss`，重启游戏。

---

## BOSS 出现方式

- **安装 StageAPI**：三个 BOSS 会进入对应楼层的 BOSS 池，正常在 BOSS 房出现。
- **未安装 StageAPI**：在进入 BOSS 房时以 **50% 概率**把原版 BOSS 替换成对应的 MOD BOSS。

---

## 控制台生成

开启调试控制台（`~`）后可以单独生成：

```
spawn 501    -- Zodiac
spawn 502    -- Man in the Moon（会同时生成两只 Moon Hand）
spawn 503    -- Moon Hand
spawn 506    -- Gambit（会同时生成骰子）
```

修改过 `entities2.xml` 或 `.anm2` 后需要**完全重启游戏**；只改 Lua 时可在控制台执行：

```
luamod mewboss
```

## 机制

### Zodiac

- 与玩家之间没有障碍时进入蓄力，警戒光束会亮起。
- 蓄力总时长随机 1~2 秒：前半段跟踪玩家，后半段方向锁定。
- 子弹弹速高、伤害 1 颗心；弹药 6 发，打空后装填。

### Man in the Moon

- 不移动，生成在房间最左侧，并把玩家推到房间右侧。
- 减伤光环：每次受到的伤害固定 **-10**，但至少保留原伤害的 **30%**。
- 初始召唤两个 Moon Hand：
  - 怪物形态：20 血、追踪玩家、有接触伤害。
  - 血量耗尽后变成石头：无敌、无接触伤害，可被玩家或子弹推动。
- 任意形态的 Moon Hand 撞上本体时，光环会短暂失效并击退场上单位，一段时间后恢复。恢复时，石头形态的手会重新活化回怪物形态。
- 技能每 5~8 秒随机施放一次：
  - 3~7 发石头弹扇形；每发有 10% 概率变成石头蜘蛛。
  - 抛射弹幕，每发射程与尺寸随机。
  - 推挤：把场上单位推向房间右侧，并清掉所有蜘蛛。

### Gambit

- 会追击玩家，骰子点数不好时会把骰子踢来踢去。
- 骰子本身无敌，可被玩家推动；撞到玩家、墙或障碍物时会重投（1 秒冷却）。
- 骰子点数决定形态：

| 点数 | 形态 | 效果 |
|---|---|---|
| 1 | 混乱 | 立刻打断当前行动，发动混乱攻击（自伤 10 点） |
| 2 | 大便 | 打断当前行动，原地蓄力 1 秒后发动大便攻击（在身后生成便便） |
| 3 | 激光 | 朝玩家的水平或竖直方向发射硫磺火 |
| 4 | 裂地波 | 向四个对角线炸开地面，摧毁沿途障碍 |
| 5 | 风暴 | 房间内落下 5 道圣光 |
| 6 | 愤怒 | 向四周发射一圈随机大小/射程的石头弹 |

- 3~6 形态攻击有 5 秒共享冷却。
- 玩家幸运越高，骰子期望越低。
